install python3
create a virtual environtment using `python3 -m venv venv`
source it to activate  `source venv/bin/activate`
install required packages using pip

-----------
pull ollama docker image (latest tag)
run `docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama`
now to use any of the model, use `docker exec -it ollama ollama run llama3`
replace llama3 with the appropriate model

-----------
pull postgres official image and run it `docker run --name postgres_container -e POSTGRES_PASSWORD=yourpwd -d postgres`
create a .env file and put `POSTGRES_PASSWORD=yourpwd`
start the app by running `uvicorn main:app --reload`
go to `http://localhost:8000/docs#` to view the swagger generated by fast api
